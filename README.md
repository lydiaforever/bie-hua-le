# 别花了别花了！

一款手机优先的轻量省钱社交游戏。用户可以设置每日预算、快速记录消费，通过火柴人的负重状态感受当天的花钱程度，并创建好友挑战房进行实时 PK。

## 初代体验版功能

- 每日预算设置与快速记账
- 账单按日期保存，第二天自动从 0 元重新计算
- 修改、删除与撤销账单
- 火柴人负重状态反馈
- 创建好友挑战房、六位邀请码与分享链接
- 好友加入房间并查看当日排行榜
- 腾讯云 CloudBase 匿名身份与 PostgreSQL 数据同步

## 项目定位

熟人社交 × 轻量记账 × 游戏化省钱。产品目标是让原本有压力的消费控制，变成朋友之间简单、有趣、可持续的每日挑战。
